# Breakglass East — Claude Code working agreement

You are working on an architectural reconstruction and professional recording-studio conversion design project.

## Critical history
Prior v0.6 modelling outputs were **rejected** for wrong console position/orientation, a missing second speaker, incorrect speaker placement, invented/provisional geometry represented too confidently, and poor rendering quality. Do **not** reuse that geometry or promote it as evidence.

## Non-negotiables
- Source-traceable, existing-conditions reconstruction FIRST. No interior finishes or equipment until camera-matched geometry passes review.
- Keep original walls/openings/structural posts, continuous existing roof geometry, live-room loft, garage access, and agricultural machinery use.
- There is no authorization for new primary partitions or raised roof structures.
- Actual legacy Spectra Sonics console and BOTH actual Geithain monitors must be independently modelled from photographs and confirmed dimensions. Never use generic stand-ins in acceptance renders.
- Control room: elite stereo mixing fundamentals before immersive/cinema expansion. Live room: grand piano, ensembles, gobos and agricultural equipment coexist.
- Calm minimalist, light-focused control room; rugged, honest farm-industrial live room. Reuse suitable old acoustic panels and wood only after inventory and performance review.
- Don't claim certified survey, architecture, acoustics or permit-ready detailing from scan screenshots, an orbit movie or photos.

## Source discipline
Maintain a source manifest of every photograph, scan view, geometric measurement and reference. Mark evidence as SURVEYED, SCAN-LABELLED, PHOTO-INFERRED, PROPOSED or UNKNOWN, with accuracy and confidence. Don't infer hidden construction as fact.
The repo is intentionally public. All code, generic design process, issue discussion, drawings and owner-approved renders can be public. Do not commit original private property photographs, restricted Drive access links, floor-level security details, or other non-public owner assets without express owner authorization. Public is a project choice, not a blocker.
The repository may remain PUBLIC by owner choice. Keep sensitive original photographs and scan data local/private unless the owner deliberately approves their release. Continue development normally with public-safe documentation, reproducible models and approved review renders.

## Process
1. Build an evidence inventory, image contact sheets, scan camera/viewpoint map and uncertainty table.
2. Build a photo-/scan-reconciled existing shell in Blender; consistent model coordinates, real units, layers/collections.
3. Create 3 camera matches with source/photo/render split views, annotated discrepancies.
4. Submit a GitHub PR with QA results; stop and request owner design review.
5. After the shell passes, accurately model real console AND 2 real Geithain speakers separately; confirm listening-axis orientation and dimensions.
6. Then develop acoustics/AV/lighting/hybrid workflow and studio fit-out in that shell, with alternate orientations supported by quantified clearances.
7. Produce Blender-engine renders and coordinated drawings from the same geometry.
8. Preserve modelling scripts, editable assets, provenance, QA checks and render settings.

## Collaboration
Use a dedicated branch `claude/<workstream>` and pull requests; avoid direct changes to main after setup. ChatGPT can inspect the same GitHub repository, create issues or comment on PRs, and independently validate outputs. Review is asynchronous via GitHub; no hidden autonomous handshake.
Read docs/FIRST_ASSIGNMENT.md and docs/ACCEPTANCE_GATES.md before doing any geometry work.

# Claude Code ↔ ChatGPT collaboration

- Keep main as reviewed baseline. Each implementation uses a separate branch and PR.
- Claude: produce modelling code, editable Blender scene, test renders, comparisons, and QA checklist.
- ChatGPT: independently examine source evidence, PR diff, model scripts, 3D/drawing correspondence and QA evidence; leave actionable PR review or GitHub issues.
- Owner: approves design decisions, priorities and tradeoffs.
- Include a plain-language model version, accuracy boundary, source list and independent review results in each PR.
- Keep raw photography, property interiors, site detail and other private assets outside PUBLIC GitHub. Only owner-approved assets enter a PRIVATE repo.
- Do not assume connected agents communicate in real time or have synchronized local files. GitHub commits and PR discussions are the documented handoff.

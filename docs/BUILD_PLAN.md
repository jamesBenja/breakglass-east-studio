# Breakglass East: build plan, packages, budget and next steps v0.3

**Not permit-ready, not construction-certified, not a quotation.** This is planning-level guidance to organise the professionals, surveys and decisions. All costs are **order-of-magnitude planning allowances** (CAD, 2026, Eastern Townships), with an expected accuracy of about **−30 % / +50 %**. They are based on typical rural Québec renovation and studio-fit-out ranges, not on quotes. Replace them with contractor bids at phase P2.

## 1. Phased roadmap
| Phase | Scope | Exit gate |
|---|---|---|
| **P0 Feasibility** (now → ~2 months) | CPTAQ / zoning / change-of-use check with the municipality; budget cap; **tape check list** (`evidence/MEASUREMENT_REQUESTS.md`); empty-room acoustic + background-noise measurements; existing electrical/HVAC/structure walk-through; machinery list | Use permitted in principle; budget cap set; shell confirmed by tape (Gate 1) |
| **P1 Design** (~2–4 months) | Architect (OAQ) + acoustician + structural engineer (OIQ) + MEP engineer develop this model into a design: orientation decision, isolation targets, HVAC noise criteria, technical power, fire separation, envelope | Coordinated design-development set; owner approval |
| **P2 Permits & procurement** (~1–3 months) | Permit drawings by the architect; tender to 2–3 contractors; long-lead items (HVAC, acoustic doors, glazing shutters, screen) | Permits; signed contracts |
| **P3 Envelope, structure, MEP rough-in** | Roof/air sealing/insulation as required; electrical service + technical power; ducted heat pump + dehumidification; flue removal / sealing; structural reinforcement if hung ceilings or the loft require it | Weather-tight, rough-ins inspected |
| **P4 Control room** | Floor, front-wall absorber, LF traps, ceiling cloud, rear diffusers (Clark wood), coves and lighting control, window shutters, door seals, cable trench, machine room | Acoustic measurement + tuning by the acoustician |
| **P5 Live room + support rooms** | Under-loft insulation cover, variable panels, gobos, floor boxes and tie-lines, iso rooms, machinery zone markings, fuel cabinet, CO/purge fan, inner garage acoustic door (option), loft guard | Measurement; farm/studio mode trial |
| **P6 Move-in & commissioning** | Clark dismantling, transport, Spectra Sonics service, RL 901K + racks install, wiring, calibration | Stereo mixing operational |
| **P7 Enhancements (optional)** | 7.1.4 speakers + subs, screen + projector, grand piano purchase, loft feasibility study | Each as a separate decision |

**Essential build = P0–P6** (stereo mixing + live recording). **Enhancements = P7** (immersive/cinema completion, piano, loft). The infrastructure for P7 (conduit, rigging, blocking, power) is installed in P3–P4 so it can be added later without rework.

## 2. Packages and dependencies
```
Zoning/CPTAQ ─┐
Tape check ───┼─► Design (arch + acoustic + struct + MEP) ─► Permits ─► Envelope/MEP rough-in ─► Control room fit-out ─► Commissioning
Acoustic meas.┘                         │                                        └─► Live/support fit-out ──┘
Machinery list ─────────────────────────┘          Clark salvage inventory ─► reuse spec ─► (P4/P5 joinery)
```
Critical dependencies:
1. **Use and permit status gates all spending beyond P0.**
2. **The HVAC route** (roof void above the sloped ceilings, ledger X4) must be confirmed before the ceiling cloud, coves or hung speakers are fixed.
3. **Floor build-up** under the control room before the monitors and console go in.
4. **Clark dismantling date** drives salvage measurement. The panels and wood must be inventoried and tested *before* Clark closes.

## 5. Clark salvage and relocation
1. **Inventory before dismantling:** each panel's size, core, fabric and mounting (photographed), each length of wood (species, dimensions, condition). Use `evidence/MEASUREMENT_REQUESTS.md` Priority 2.
2. **Reuse rule:** reuse panels only where their tested or declared absorption fits the acoustician's spec (otherwise use them as gobos or in the live room). Reclaimed wood becomes the rear diffusers, window benches, gobo faces and the variable-panel reflective faces.
3. **Move:**
   - Console: crate it, have a tech remove and pack the modules if advised, and transport it climate-controlled.
   - RL 901Ks: original boxes or custom crates (48 kg each, two people).
   - Racks: transport loaded only if the rails are rated.
   - **Measure every door and route** at Clark and at Ways Mills.
4. Schedule the move **after** P4 measurement, so equipment doesn't sit in dust.
